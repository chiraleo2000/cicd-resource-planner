# References — Gemini CICD Analysis

วางเอกสารอ้างอิงที่ต้องการ add เป็น sources ใน NotebookLM ในนี้:

## เอกสารที่แนะนำ
- TOR / ข้อกำหนดจ้าง (PDF/DOCX)
- Requirements Specification (XLSX/DOCX)
- UAT/SIT Test Cases
- `CICD Blueprint Service V0.2.pdf`
- `CICD Internal Service Proposal.pdf`
- `Cybersecurity-Guidelines-V0.2.pdf`
- `SecureDev-Architecture-V0.2.pdf`
- `CICD_Tool_Resource_Matrix.xlsx`

## วิธีใช้
1. Copy ไฟล์อ้างอิงมาไว้ใน folder นี้
2. เปิด NotebookLM → Add Sources → upload ไฟล์เหล่านี้
3. Add ร่วมกับ `skills/gemini/SKILL.md`
4. NotebookLM จะ cross-reference ระหว่าง sources อัตโนมัติ
