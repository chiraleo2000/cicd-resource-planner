# References — Gemini CICD Analysis

วางเอกสารอ้างอิงที่ต้องการ add เป็น sources ใน NotebookLM ในนี้:

## เอกสารที่แนะนำ
- TOR / ข้อกำหนดจ้าง (PDF/DOCX)
- Requirements Specification (XLSX/DOCX)
- UAT/SIT Test Cases
- Comments / Review feedback
- แนวปฏิบัติการพัฒนาซอฟต์แวร์ฯ (PDF)
- CICD Blueprint Service (PDF)
- CICD_Tool_Resource_Matrix.xlsx

## วิธีใช้
1. Copy ไฟล์อ้างอิงมาไว้ใน folder นี้
2. เปิด NotebookLM → Add Sources → upload ไฟล์เหล่านี้
3. Add ร่วมกับ SKILL.md จาก partnership-intelligence-pre-mou-agent-knowledge/
4. NotebookLM จะ cross-reference ระหว่าง sources อัตโนมัติ
5. ใช้ large context window อ่านเอกสารทั้งฉบับ ไม่ต้องย่อ

## Tips
- แนบเอกสารหลายไฟล์พร้อมกัน — NotebookLM อ่านทั้งหมดได้
- สร้าง Audio Overview สำหรับสรุปให้ผู้บริหารฟัง
- ใช้ Notebook Guide ถาม FAQ ได้ทันที
